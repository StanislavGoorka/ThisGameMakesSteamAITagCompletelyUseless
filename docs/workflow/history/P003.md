# P003 — konfiguracja stylu

Data: 2026-11-10. Zależność P002 ukończona.

Dodano `.clang-format` oparty na LLVM, z czterema spacjami, bez tabulatorów, klamrami Allman i końcami linii LF. `.editorconfig` ustawia UTF-8 bez BOM, końcowy znak nowej linii oraz cztery spacje dla C i C++. Domyślne LF i wyjątek CRLF dla PowerShell odpowiadają `.gitattributes`. Wyjątek Markdown zachowuje spacje oznaczające twarde łamanie wiersza. README opisuje konfigurację oraz konwencje `snake_case` i `PascalCase`, których formatter nie egzekwuje.

## Weryfikacja

Komendy uruchomiono w PowerShell z katalogu repozytorium. Początkowy `git -c safe.directory=D:/ThisGameMakesSteamAITagCompletelyUseless status --short` był czysty. Walidator przed i po zmianie: PASS, 115 zadań. `clang-format --version`: 16.0.4, exit 0.

Tymczasowa próbka w ignorowanym `tmp/` miała tabulator, CRLF i klamry w tej samej linii. Początkowe sprawdzenie zwróciło exit 1 z diagnostyką formatu. Pierwsze formatowanie dało oczekiwane bajty, drugie dało identyczny wynik. Końcowe sprawdzenie próbki i istniejącego C++ zakończyło się kodem 0. Próbkę usunięto. Poniżej komendy sprawdzenia:

```powershell
$ErrorActionPreference = 'Stop'
$styleTemp = New-Item -ItemType Directory -Path tmp -Force
$styleSample = Join-Path $styleTemp.FullName ("p003-{0}.cpp" -f [guid]::NewGuid())
try {
    $unformatted = "struct DeliveryState{int cargo_count;};`r`nint count_cargo(DeliveryState state){`r`n`treturn state.cargo_count;`r`n}`r`n"
    $expected = "struct DeliveryState`n{`n    int cargo_count;`n};`nint count_cargo(DeliveryState state)`n{`n    return state.cargo_count;`n}`n"
    [IO.File]::WriteAllText($styleSample, $unformatted)
    clang-format --style=file --dry-run --Werror $styleSample
    if ($LASTEXITCODE -ne 1) { throw "Expected exit 1 for unformatted sample, got $LASTEXITCODE" }

    clang-format --style=file -i $styleSample
    if ($LASTEXITCODE -ne 0) { throw 'First formatting pass failed' }
    $firstBytes = [Convert]::ToBase64String([IO.File]::ReadAllBytes($styleSample))
    $expectedBytes = [Convert]::ToBase64String([Text.Encoding]::UTF8.GetBytes($expected))
    if ($firstBytes -cne $expectedBytes) { throw 'Formatted sample differs from expected bytes' }

    clang-format --style=file -i $styleSample
    if ($LASTEXITCODE -ne 0) { throw 'Second formatting pass failed' }
    $secondBytes = [Convert]::ToBase64String([IO.File]::ReadAllBytes($styleSample))
    if ($secondBytes -cne $firstBytes) { throw 'Second formatting pass changed the sample' }
    clang-format --style=file --dry-run --Werror $styleSample tests/unit/build_tests.cpp
    if ($LASTEXITCODE -ne 0) { throw 'Final formatting check failed' }
} finally {
    if (Test-Path -LiteralPath $styleSample) { Remove-Item -LiteralPath $styleSample }
}
```

Kontrole końcowe: wszystkie exit 0, bez błędów białych znaków.
