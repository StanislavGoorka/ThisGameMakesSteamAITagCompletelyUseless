# P012 — Losowanie z przedziału

Data 2026-11-11. Zależność P011 ukończona.

`SplitMix64::next_in_range` przyjmuje domknięty przedział `uint64_t`. Odwrócone granice zwracają `std::nullopt`, a równe granice zwracają jedyną wartość. Oba przypadki zachowują stan generatora. Pełny zakres zwraca jeden wynik `next_u64()`. Dla przedziału zawierającego `n` wartości funkcja odrzuca wszystkie surowe wyniki mniejsze niż `2⁶⁴ mod n`. Pozostałe wyniki tworzą ciąg o długości będącej wielokrotnością `n`, więc każda reszta występuje tyle samo razy. [Generator](../../../src/core/splitmix64.hpp) · [Architektura](../../ARCHITECTURE.md)

`core_splitmix64` nadal sprawdza wektory P011. Nowe przypadki sprawdzają oba końce przedziału przy `UINT64_MAX`, powtarzalność dla tego samego seeda, pełny zakres, przedział jednoelementowy i odwrócony. Dodatkowe wektory pokrywają ponowienie po dwóch kolejnych odrzuceniach oraz przyjęcie losowania równego progowi. Oczekiwane wartości obliczono niezależnie w JavaScript `BigInt`, używając dokładnej wartości `2⁶⁴` do wyznaczenia progu. [Testy](../../../tests/unit/splitmix64_tests.cpp)
