# P038-04

Data: 2026-11-12. Krok 5/5.

Początek: status czysty, walidator PASS (164 zadania), P038-03 completed.
Wykorzystano AGENTS, next-step, cpp-core-step, WORKFLOW, STATE/NEXT,
poprzedni raport, ARCHITECTURE, GAME_DESIGN, TESTING i CHECKPOINT_FORMAT.

Dodano wyłącznie integracyjny test przerwania; kod produkcyjny bez zmian.
Worker uruchamia rzeczywisty save_checkpoint_file. Lokalnie przechwycone
WriteFile/FlushFileBuffers/MoveFileExW delegują do Win32 i zatrzymują proces
po realnych operacjach: zapis17 bajtów do temp, flush40 bajtów, publikacja bak,
publikacja main. Makra są ograniczone do jednej jednostki testu i od razu
usuwane; brak hooków/callbacków w produkcyjnym API i kopii protokołu save.

Rodzic uruchamia worker przez CreateProcessW z CREATE_NO_WINDOW. Zdarzenie
potwierdza dotarcie do granicy, TerminateProcess kończy proces kodem99,
WaitForSingleObject potwierdza zakończenie; brak opierania testu na sleep rodzica.
Timeouty rodzica są10s, osierocony worker kończy się po20s; CTest ma limit45s.
Dokumentacja sprawdzona: [CreateProcessW](https://learn.microsoft.com/en-us/windows/win32/api/processthreadsapi/nf-processthreadsapi-createprocessw),
[TerminateProcess](https://learn.microsoft.com/en-us/windows/win32/api/processthreadsapi/nf-processthreadsapi-terminateprocess),
[WaitForMultipleObjects](https://learn.microsoft.com/en-us/windows/win32/api/synchapi/nf-synchapi-waitformultipleobjects).

Cztery niezależne wektory × cztery granice =16 przerwań na uruchomienie.
Main pozostaje poprzedni przed ostatnią publikacją; bak pozostaje starszy
przed jego publikacją, potem jest poprzednim main. Temp ma17/40 bajtów albo
znika po zamianie. Test porównuje dokładne bajty i pełne RunState po restore,
także opłacony impuls/dług. Retry po każdej granicy daje poprawny main i bak.
Ścieżka zawiera polskie znaki i spację. Brak rodzica i katalog zajmujący
ścieżkę temp dają odmowę bez utraty poprzednich plików; retry działa.

ctest --preset windows-debug --output-on-failure

ctest --preset windows-release --output-on-failure
.\build\windows-msvc\Debug\windows_checkpoint_interrupt_tests.exe

rg --files src tests tools -g '*.hpp' -g '*.cpp' | ForEach-Object { clang-format --style=file --dry-run --Werror $_ }
