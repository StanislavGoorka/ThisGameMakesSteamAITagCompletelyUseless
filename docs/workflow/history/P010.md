# P010 — Najkrótsza trasa BFS

Data 2026-11-11. Zależność P009 ukończona.

`shortest_route` przyjmuje maski portów w kolejności `NodeId` oraz identyfikatory startu i celu. Zwraca najkrótszą trasę z oboma końcami, pojedynczy węzeł dla `start == cel` albo pusty wektor dla nieosiągalnego celu. BFS odwiedza sąsiadów w kolejności N, E, S, W przez `connected_neighbors` i zapisuje poprzednika przy pierwszym odkryciu węzła. [Implementacja](../../../src/core/grid_pathfinding.hpp)

`core_grid_pathfinding` sprawdza wybór krótszej trasy mimo wcześniejszego kierunku dłuższej, objazd po zamknięciu krawędzi, identyczny start i cel, nieosiągalny cel, brak zawijania między wierszami i remisy w symetrycznym układzie.
