# P011 — Deterministyczny PRNG i wektory

Data 2026-11-11. Zależność P010 ukończona.

Wybrano SplitMix64, który przechowuje jeden 64-bitowy stan i obsługuje każdą wartość `RunSeed`. Stan początkowy jest równy seedowi. `next_u64()` dodaje stały przyrost modulo 2⁶⁴, miesza nowy stan i zwraca pełną wartość `uint64_t`. [Typ seeda](../../../src/core/identifiers.hpp) · [Generator](../../../src/core/splitmix64.hpp) · [Implementacja referencyjna Sebastiana Vigny](https://prng.di.unimi.it/splitmix.c)

`core_splitmix64` porównuje pierwsze cztery wyniki dla seeda `0` i `UINT64_MAX` z ustalonymi wektorami. Wektory obliczono niezależnie w JavaScript `BigInt` według wzoru ze źródła referencyjnego, wyznaczając stan w kroku `n` jako `seed + n × przyrost` modulo 2⁶⁴. Maksymalny seed sprawdza zawinięcie stanu przy pierwszym wywołaniu. Drugi test porównuje po 64 przeplatane wywołania dwóch instancji z tym samym seedem. [Test](../../../tests/unit/splitmix64_tests.cpp) · [Rejestracja w CTest](../../../CMakeLists.txt)
