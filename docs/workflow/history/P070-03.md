Data: 2026-11-13.

TextRenderer składa kompletne wiersze katalogowe z liczbowymi wartościami w jeden layout. Budowa nowego obiektu nie zmienia poprzedniego, a zbyt mały obszar pomija cały blok.

Początek: czysty git status, walidator PASS i zależności completed.
Zakres wyznaczają pliki lokalnego commitu tego ID; cudzych zmian nie było.

Weryfikacja: cmake --preset windows-msvc; cmake --build --preset windows-debug i windows-release -- /nr:false; ctest --preset windows-debug --output-on-failure i windows-release: po 112/112 PASS. clang-format --style=file --dry-run --Werror src/tests/tools PASS. CMAKE_BUILD_PARALLEL_LEVEL=4, MSBUILDDISABLENODEREUSE=1; build TEMP/TMP=repo/build/temp, test TEMP domyślny C:. windows_text_renderer rozszerzono o kompletne trzy wiersze, brak ID/pustą listę, czarny bufor po odmowie szerokości oraz rzeczywiste cele przy 96/144/192 DPI.

Kontrole zakończenia z katalogu repo:

```powershell

git -c safe.directory=D:/ThisGameMakesSteamAITagCompletelyUseless diff --cached --check
```

sprawdzane przez git show --stat --oneline HEAD i git rev-parse HEAD.
