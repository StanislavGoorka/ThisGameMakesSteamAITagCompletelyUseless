# P007 — Maska portów

Data 2026-11-11. Zależność P006 ukończona.

[Nagłówek `PortMask`](../../../src/core/port_mask.hpp) przypisuje kierunkom N, E, S i W kolejno bity 0, 1, 2 i 3. `from_bits` akceptuje wszystkie wartości od 0 do 15 i zwraca pusty `std::optional` dla liczb całkowitych spoza tego zakresu. `rotate_clockwise` przesuwa porty o jedną pozycję w kolejności N → E → S → W → N.

[Test `core_port_rotation`](../../../tests/unit/port_mask_tests.cpp) porównuje wyniki obrotu dla wszystkich 16 masek z tabelą oczekiwanych wartości. Dla każdej maski sprawdza także zachowanie liczby portów i powrót po czterech obrotach. Przypadki błędne obejmują −1, 16, 256 i maksymalną wartość `uint64_t`. Wartość 256 wykrywa zawężenie przed sprawdzeniem zakresu. [Konfiguracja CMake](../../../CMakeLists.txt) rejestruje test w CTest.
