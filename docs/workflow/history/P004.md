# P004 — presety Windows

Data 2026-11-10. Zależność P003 ukończona.

Dodano `CMakePresets.json` z konfiguracją `windows-msvc` dla Visual Studio 2022 i MSVC x64. Presety `windows-debug` i `windows-release` wybierają odpowiednią konfigurację kompilacji i CTest. Wspólny katalog `build/windows-msvc/` oddziela pliki presetów od wcześniejszego ręcznego builda w `build/`. Po wykonaniu testów komendy trafiły do [README](../../../README.md).

## Weryfikacja

Komendy wykonano w PowerShell z katalogu repozytorium. CMake i CTest z PATH zgłosiły wersję 3.26.4. Konfiguracja od podstaw wykryła MSVC 19.44.35228.0 i Windows SDK 10.0.22621.0. `CMakeCache.txt` potwierdził platformę `x64` i `BUILD_TESTING=ON`. Obie konfiguracje zbudowały `core_tests.exe` w osobnych podkatalogach Debug i Release. CTest zaliczył `core_build_smoke` w obu konfiguracjach (po 1/1). Każda z poniższych komend zakończyła się kodem 0.

```powershell
cmake --preset windows-msvc
cmake --build --preset windows-debug
ctest --preset windows-debug --output-on-failure
cmake --build --preset windows-release
ctest --preset windows-release --output-on-failure
git -c safe.directory=D:/ThisGameMakesSteamAITagCompletelyUseless check-ignore build/windows-msvc/CMakeCache.txt
```

Walidator projektu zaliczył 115 zadań przed zmianą i po niej. Kontrola białych znaków przeszła dla zmian roboczych i przygotowanych do commitu.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Validate-Project.ps1
git -c safe.directory=D:/ThisGameMakesSteamAITagCompletelyUseless diff --check
git -c safe.directory=D:/ThisGameMakesSteamAITagCompletelyUseless diff --cached --check
```

Sprawdzono jedną lokalną instalację narzędzi. Test celowego błędu z P002 i regresja walidatora nie były częścią tej weryfikacji.
