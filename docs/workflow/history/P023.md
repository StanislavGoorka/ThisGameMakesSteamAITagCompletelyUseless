# P023 — Podgląd na kopii

Data 2026-11-11. Początkowy HEAD `156ad9b`, drzewo czyste. Zależność P022-02 ukończona i zaimplementowana. Walidator początkowy zaliczył 127 zadań.

## Rezultat

[turn_preview.hpp](../../../src/core/turn_preview.hpp) dodaje `preview_turn(const GameState&, const Command&)`, delegujące bezpośrednio do `resolve_turn`. Zwracany TurnResult posiada niezależny stan dzięki istniejącemu resolverowi; nie ma dodatkowej kopii, osobnej kolejności faz ani powielonej klasyfikacji. API nie przyjmuje usług plikowych, achievementów ani RNG.

[Korpus testów](../../../tests/unit/turn_preview_tests.cpp) porównuje wszystkie pola stanu, accepted i outcome podglądu z wykonaniem oraz jawnym oczekiwanym wynikiem. Obejmuje legalne move/rotate/wait, błędne akcje z gotowym pakietem i kontaktami, wprowadzenie/dostawę, pojedynczy ruch pakietu i impulsu, obrót zmieniający obie trasy, wejście na impuls oraz zwycięstwo, śmierć i przeciążenie 47→48. Wszystkie trzy komendy są odrzucane dla completed/death/overload bez faz.

Każdy scenariusz powtarza podgląd trzykrotnie i po każdym odczycie porównuje pełny live state i komendę. Mutacja pakietu, wyjścia, flag i kolekcji impulsów w zwróconym stanie nie zmienia live state, innego wyniku ani kolejnego podglądu. Zewnętrzny RNG zachowuje sekwencję; jest poza API, nie jest to dowód rollbacku generatora.

```powershell
cmake --build --preset windows-debug
ctest --preset windows-debug --output-on-failure
powershell -NoProfile -ExecutionPolicy Bypass -File .local/Test-P023Mutation.ps1

git -c safe.directory=D:/ThisGameMakesSteamAITagCompletelyUseless diff --check
git -c safe.directory=D:/ThisGameMakesSteamAITagCompletelyUseless diff --cached --check
```
