# P005 — CI Windows

Data 2026-11-10. Zależność P004 ukończona.

[Workflow Windows CI](../../../.github/workflows/windows.yml) uruchamia konfigurację, kompilację i CTest w osobnych zadaniach Debug i Release po pushu do `main` i przy pull requestach. Wybrano `windows-2022`, którego obraz zawiera Visual Studio 2022 i CMake zgodne z presetem `windows-msvc`. Macierz kończy oba zadania niezależnie od wyniku drugiej konfiguracji. [Dokumentacja obrazu Windows 2022](https://github.com/actions/runner-images/blob/main/images/windows/Windows2022-Readme.md).

## Weryfikacja

LLVM 16.0.4 zwrócił kod 0 w obu poleceniach kontroli YAML. Odczyt w formacie kanonicznym potwierdził strukturę zdarzeń, macierzy i kroków, które sprawdzono z dokumentacją GitHub Actions. [Składnia workflow](https://docs.github.com/en/actions/reference/workflows-and-actions/workflow-syntax).

```powershell
yaml-bench --verify .github/workflows/windows.yml
yaml-bench --canonical .github/workflows/windows.yml
```

Komendy CMake i CTest wykonano z katalogu repozytorium oraz od zera w tymczasowej kopii zawierającej wyłącznie pliki CMake i źródło testu. MSVC 19.44.35228.0 zbudował obie konfiguracje x64, a CTest zaliczył `core_build_smoke` w każdej z nich (1/1). Wszystkie poniższe komendy zakończyły się kodem 0.

```powershell
cmake --preset windows-msvc
cmake --build --preset windows-debug
ctest --preset windows-debug --output-on-failure
cmake --build --preset windows-release
ctest --preset windows-release --output-on-failure
```

Walidator projektu zaliczył 115 zadań przed zmianą i po niej. Kontrola białych znaków przeszła dla zmian roboczych i przygotowanych do commitu.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Validate-Project.ps1
git -c safe.directory=D:/ThisGameMakesSteamAITagCompletelyUseless diff --check
git -c safe.directory=D:/ThisGameMakesSteamAITagCompletelyUseless diff --cached --check
```

Pierwszy przebieg na GitHub Actions pozostaje do sprawdzenia po publikacji workflow. Weryfikację składni wykonano parserem YAML LLVM i przez porównanie z dokumentacją GitHub Actions. Pobranie `actionlint` zatrzymał brak połączenia z GitHub z lokalnej powłoki.
