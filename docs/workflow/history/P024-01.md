# P024-01 — Kanoniczny hash pełnego stanu

Data 2026-11-11. Początkowy HEAD `0beefed`, drzewo czyste. P024 ukończone jako podział planu; zależność bieżącego wpisu ukończona. Walidator początkowy zaliczył 131 zadań.

## Rezultat i format v1

[tools/replay/state_hash.hpp](../../../tools/replay/state_hash.hpp) implementuje `closed_circuit::developer::state_hash(const GameState&) -> uint64_t`. Hash nie mutuje stanu, nie alokuje, nie zależy od adresów, paddingu ani std::hash. Narzędzie jest poza core i paczką gry; dodatkowa ścieżka include CMake dotyczy wyłącznie developer_state_hash_tests.

FNV-1a 64-bit rozpoczyna od 14695981039346656037. Każdy bajt wykonuje XOR, potem mnożenie przez 1099511628211 modulo 2^64. To hash niekryptograficzny do regresji, bez gwarancji braku kolizji.

Jawny strumień bajtów w tej kolejności:

1. Wersja kodowania 1 jako uint32 little-endian.
2. 49 bajtów ports.bits() w kolejności NodeId 0–48.
3. 49 bajtów rotatable_nodes i 49 blocked_nodes, bool jako 0/1.
4. player_position uint8, player_integrity uint8, turns_taken uint32 little-endian.
5. packet: bajt tagu 0/1; dla 1 position uint8 i target uint8.
6. 49 bajtów powered_nodes i 49 receiver_nodes, bool jako 0/1.
7. sector_entry i sector_exit: każde z tagiem 0/1, przy 1 dodatkowy uint8 NodeId.
8. Liczba pulses uint64 little-endian; każdy element w kolejności przechowywania: EntityId uint32 little-endian i position uint8.

Brak optional i NodeId0 mają różne kodowanie. Kolejność impulsów jest częścią dokładnego stanu, nie jest sortowana. Outcome jest wyliczany, więc nie ma go w strumieniu. Nie dodano seeda ani RNG do GameState.

## Testy i niezależne wektory

Nowy [test](../../../tests/unit/state_hash_tests.cpp) obejmuje każdy indeks ports i czterech tablic bool, pozycję gracza, HP0/3/255, tury0/48/UINT32_MAX, brak pakietu i oba jego pola, brak/0/48 wejścia i wyjścia, ID impulsów0/UINT32_MAX oraz pozycje0/48. Zmiana każdego elementu, liczby i kolejności impulsów jest rozróżniana w korpusie. Każde wywołanie porównuje pełny stan przed/po; scenariusz pełny ma niepusty pakiet i impulsy. Kopia oraz trzy powtórzenia dają zgodne hashe. Nie jest to dowód nieistnienia wszystkich kolizji.

| Minimalny: pola domyślne, gracz0, HP3 | 266 | 13972979675829650943 |
| Pełny: dane opisane poniższym skryptem | 280 | 5610859398122436359 |

```powershell
$bytes = [System.Collections.Generic.List[byte]]::new()
function Add-LE([bigint]$value, [int]$width) {
    for ($i=0; $i -lt $width; $i++) { $bytes.Add([byte] ($value % 256)); $value = [bigint]::Divide($value, 256) }
}
function Get-Vector([bool]$full) {
    $bytes.Clear()
    Add-LE 1 4
    for ($i=0; $i -lt 49; $i++) { $bytes.Add([byte] ($(if ($full) { $i % 16 } else { 0 }))) }
    foreach ($mod in @(2,3)) { for ($i=0; $i -lt 49; $i++) { $bytes.Add([byte] ($full -and $i % $mod -eq 0)) } }
    $bytes.Add([byte] ($(if ($full) {48} else {0})))
    $bytes.Add([byte] ($(if ($full) {255} else {3})))
    Add-LE $(if ($full) {4294967295} else {0}) 4
    $bytes.Add([byte]$full)
    if ($full) { $bytes.Add(0); $bytes.Add(48) }
    foreach ($mod in @(5,7)) { for ($i=0; $i -lt 49; $i++) { $bytes.Add([byte] ($full -and $i % $mod -eq 0)) } }
    $bytes.Add([byte]$full); if ($full) { $bytes.Add(0) }
    $bytes.Add([byte]$full); if ($full) { $bytes.Add(48) }
    Add-LE $(if ($full) {2} else {0}) 8
    if ($full) { Add-LE 4294967295 4; $bytes.Add(48); Add-LE 0 4; $bytes.Add(0) }
    [bigint]$hash = [bigint]::Parse('14695981039346656037')
    [bigint]$modulus = [bigint]::Pow(2,64)
    foreach ($value in $bytes) { $hash = (($hash -bxor [bigint]$value) * 1099511628211) % $modulus }
    'full={0} bytes={1} hash={2}' -f $full,$bytes.Count,$hash
}
Get-Vector $false
Get-Vector $true
```
